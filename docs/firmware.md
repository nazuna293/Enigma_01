# ファームウェアの書き込み

> [!NOTE]
> **使う人**：全員（組み立ての途中の確認 [4-2](build-guide.md#4-2-途中の確認)・動作確認 [5章](build-guide.md#5-動作確認)）。親指キーの配列やキーマップを変える人  
> **使う道具**：USB-Cケーブル（データ通信ができるもの）・パソコン  
> **難しさ**：低

## 入手する

[Releases](https://github.com/nazuna293/zmk-Enigma_01-user-config/releases) から `.uf2` をダウンロードします。GitHub のアカウントは要りません。ファームは2つの版があり、キーの並び（初期キーマップ）は同じです。

| ファーム（.uf2） | 版 | キーマップを画面で変えられる範囲 |
|:-|:-|:-|
| `Enigma_01_dya_layout_a.uf2` | **DYA 版**（おすすめ） | キーの割り当て・レイヤー・**同時押し・マクロ**（DYA Studio）。ZMK Studio も使えます |
| `Enigma_01_official_layout_a.uf2` | 公式版 | キーの割り当て・レイヤー（ZMK Studio・DYA Studio） |

迷ったら DYA 版を選んでください。違いの詳しいことは [ユーザー向けリポジトリ](https://github.com/nazuna293/zmk-Enigma_01-user-config#2つの版) にあります。

どちらも 1.0u 配列用です。1.5u・2.0u の人も、まずこれを書き込み、組み上げたあと「[配列を切り替える](#配列を切り替える)」で切り替えます。

## 書き込む

1. USB-Cケーブルでパソコンとつなぐ（ケースに入れた後は、電源を入れておく）
2. リセットボタンを、すばやく2回押す
   - 組み立ての途中は、XIAO のリセットボタンを直接押します
   - ケースに入れた後は、アッパーケースのリセットボタンを押します（位置はビルドガイドの [7章](build-guide.md#7-使い始める) の図）。B を押したまま最下段の左端を押しても同じです
3. パソコンに USB ドライブとして表示されたら、`.uf2` をドライブにコピーする
4. コピーが終わると自動で再起動し、ドライブの表示が消える
5. キーの入力を確かめる

> [!NOTE]
> コピーの途中や直後に「ファイルのコピー中にエラーが発生しました」などのメッセージが出ることがありますが、**書き込みは終わっています**。「スキップ」を押して先へ進んでください。パソコンの環境によって出るもので、XIAO の不具合ではありません。

## 配列を切り替える

1.5u・2.0u の親指キー（[親指キーの配列](thumb_key.md)）の人は、書き込んだあと、物理配置（レイアウト）を切り替えます。切り替えた内容は、キーボード本体に残ります。

1. Chrome か Edge で [ZMK Studio](https://zmk.studio) か [DYA Studio](https://studio.dya.cormoran.works) を開き、USB でつなぐ
2. 「ロックされている」と出たら、B を押したまま D の位置（`studio_unlock`）を押す
3. レイアウトの選択で、自分の配列（1.5u か 2.0u）を選ぶ

詳しい画面は、ユーザー向けリポジトリの [ZMK Studio](https://github.com/nazuna293/zmk-Enigma_01-user-config/blob/dya/docs/ZMK_Studio.md)・[DYA Studio](https://github.com/nazuna293/zmk-Enigma_01-user-config/blob/dya/docs/DYA_Studio.md) の説明にあります。

## キーマップを変える

キーの割り当ては、上と同じ Studio の画面から変えられます。書き込み直しは要りません。

| 方法 | 変えられるもの |
|:-|:-|
| DYA Studio | キーの割り当て・レイヤー名。DYA 版なら同時押し・マクロも |
| ZMK Studio | キーの割り当て・レイヤー名 |
| キーマップのファイルを直接直す（慣れた人向け） | すべて（タップと長押しの判定時間など） |

それぞれの手順は [ユーザー向けリポジトリ](https://github.com/nazuna293/zmk-Enigma_01-user-config#キーマップを変える) にあります。ファイルを直す場合は、できたファームを上の「[書き込む](#書き込む)」と同じ手順で入れます。
