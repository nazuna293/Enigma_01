# ファームウェアの書き込み

> [!NOTE]
> **使う場面**：組み立ての途中の確認（[4-2](build-guide.md#4-2-途中の確認)）・動作確認（[5章](build-guide.md#5-動作確認)）・親指キーの配列やキーマップを変えたとき  
> **使う物**：USB-Cケーブル（データ通信ができるもの）・パソコン  
> **難しさ**：低

ファームは親指キーの配列ごとに分かれています。使う配列のものを選んでください（[親指キーの配列](thumb_key.md)）。

| ファーム（.uf2） | 配列 |
|:-|:-|
| `Enigma_01 layout_a` | 1.0u |
| `Enigma_01 layout_b` | 1.5u |
| `Enigma_01 layout_c` | 2.0u |

## 入手する

**キーマップを変えずに使う場合（おすすめ）**

[Releases](https://github.com/nazuna293/zmk-Enigma_01-user-config/releases) から、使う配列の `.uf2` をダウンロードします。GitHub のアカウントは要りません。

**キーマップを変えたい場合**

1. GitHub のアカウントを作り、[ユーザー向けリポジトリ](https://github.com/nazuna293/zmk-Enigma_01-user-config)を自分のアカウントにフォーク（コピー）する
2. フォークしたリポジトリでキーマップを編集すると、GitHub Actions が自動でファームを作ります
3. Actions の実行結果の「Artifacts」から zip をダウンロードし、中の `.uf2` を使う

- Actions の成果物は、一定の期間（初期設定では90日）で消えます。必要なファームは手元に保存しておいてください
- キーマップの書き方は、kot さんの [zmk-config-roBa のキーマップのガイド](https://github.com/kot149/zmk-config-roBa/blob/main/docs/keymap.md)がとても参考になります

## 書き込む

1. USB-Cケーブルでパソコンとつなぐ（ケースに入れた後は、電源を入れておく）
2. リセットボタンを、すばやく2回押す
   - 組み立ての途中は、XIAO のリセットボタンを直接押します
   - ケースに入れた後は、アッパーケースのリセットボタンを押します。押しにくいときは [リセットボタン](reset_button.md)
3. パソコンに USB ドライブとして表示されたら、`.uf2` をドライブにコピーする
4. コピーが終わると自動で再起動し、ドライブの表示が消える
5. キーの入力を確かめる

> [!NOTE]
> 書き込みの途中や直後に、エラーのメッセージが出ることがありますが、書き込みは終わっています。詳しくは[ファーム書き込み時のエラー](firm_error.md)です。
