# ファームウェアの書き込み
Enigma_01はファームウェアを書き込んだ状態でお届けします。親指キーの配列を変えたとき、キーマップを変えたときに書き込み直します。

## 必要なもの
・USB-Cケーブル（データ通信ができるもの）  
・パソコン  
・ファームウェア（.uf2）：[ユーザー向けリポジトリ](https://github.com/nazuna293/zmk-Enigma_01-user-config)から入手します。親指キーの配列ごとに分かれています。

|ファームウェア(.uf2)|配列|
|:-|:-|
|Enigma_01 layout_a|1.0u配列|
|Enigma_01 layout_b|1.5u配列|
|Enigma_01 layout_c|2.0u配列|

## 書き込みの手順
1. Enigma_01の電源を入れ、パソコンとUSB-Cケーブルでつなぐ。
2. アッパーケースのリセットボタンを、すばやく2回押す。  
   押しにくいときは[リセットボタン](reset_button.md)を確認してください。
3. パソコンにUSBドライブとして表示されたら、ファームウェア（.uf2）をドライブにコピーする。
4. コピーが終わると自動で再起動し、ドライブの表示が消える。
5. キーの入力を確認する。
<!-- 写真 fw_drive.jpg：パソコンに表示されたUSBドライブと、.uf2 をドラッグしているところの画面 -->

> [!NOTE]
> 書き込みの途中や直後に、エラーのメッセージが出ることがありますが、書き込みは完了しています。詳しくは[こちら](firm_error.md)です。
