# うまく動かないとき

|症状|確認すること|
|:-|:-|
|反応しないキーがある|キースイッチのピンが曲がっていないか（[キースイッチの取り付け](keyswitch.md)）。別のスイッチと入れ替えて、スイッチとソケットのどちらが原因かを切り分ける|
|ほかのキーと違う文字が入力される|親指キーの配列とファームウェア（layout_a/b/c）が合っているか（[ファームウェアの書き込み](firmware.md)）|
|記号の位置がずれる（US配列とJIS配列）|パソコン側のキーボードの設定。Enigma_01にはUS配列とJIS配列の違いを吸収する機能があります（README の「搭載したカスタム機能」）|
|Bluetoothでつながらない|BT_CLR_ALLでペアリング情報を消し、パソコン側の登録も削除してから、もう一度ペアリングする|
|リポバッテリーで動かない／充電されない|電源オンの状態でのみUSBから充電されます。コネクタの極性と差し込みを確認する（[リポバッテリー取付方法](battery.md)）|
|リセットボタンが押せない|基板を手前にずらす（[リセットボタン](reset_button.md)）|
|ファームウェアの書き込みでエラーが出る|書き込みは完了しています（[こちら](firm_error.md)）|
